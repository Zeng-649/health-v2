# 智骨科技 · 骨科智慧医疗演示网站

面向创业路演答辩视频录制的离线可演示站点，原生 HTML5 + CSS3 + ES6，无框架、无构建、无 CDN 依赖。

## 环境依赖与一键安装

| 依赖项 | 要求 | 用途 |
| --- | --- | --- |
| 操作系统 | Windows 10 / 11 | 运行 VBS 启动脚本与 JDK |
| Java | JDK 17 及以上（推荐 Microsoft OpenJDK / Azul Zulu / Oracle JDK） | 运行 `server.java` 静态服务与 AI 反向代理；**不装也能双击 index.html 离线演示** |
| 浏览器 | Chrome / Edge 现代版本 | 页面渲染（无需任何插件） |
| 网络 | 可选 | 仅真实 AI 生成需要联网；断网自动回退内置知识库 |
| Node.js / npm / Python | **不需要** | 全站零构建、零包管理器依赖 |

**一键安装脚本**：双击项目目录下的 `环境安装.vbs` 即可完成环境准备：

1. 自动检测 Java 是否已安装；已安装则显示当前版本并确认满足要求；
2. 未安装时弹窗询问，选择「是」即通过系统自带 winget 包管理器**自动静默安装 Microsoft OpenJDK 17**（需联网，约 1~5 分钟）；
3. 本机没有 winget 时自动打开官方下载页，并给出三步手动安装指引（下载 MSI → 双击安装 → 重新双击 `一键打开.vbs`）；
4. 安装完成后自动验证安装目录；因系统环境变量需注销/重启后刷新，脚本会明确提示后续操作。

> 提示：JDK 安装包体积约 180MB，路演机建议提前安装；无 Java 环境时整个演示仍可双击 `index.html` 离线进行。

## 部署运行步骤

### 本地部署（三选一）

#### 方式一：直接双击 index.html（离线演示）

无需任何环境，双击 `index.html` 即可在浏览器中打开：

- 首页、六步全流程、AI 对话、图片灯箱、Excel 导出全部可用；
- AI 对话、影像检测、诊疗方案、恢复计划自动使用内置知识库（真实 AI 不可用），无长时间等待；
- 页面顶部会显示一条可关闭的浅色提示「当前为直接打开模式，AI 使用内置知识库；双击『一键打开.vbs』可启用真实 AI」。

#### 方式二：双击 一键打开.vbs（推荐，真实 AI）

双击项目目录下的 `一键打开.vbs`：

- 无黑色命令行窗口，服务在后台隐藏启动（JDK 17，约数秒就绪）；
- 就绪后自动用默认浏览器打开 <http://localhost:5500>，此时 AI 为真实 DeepSeek 内容；
- 服务 PID 记录在同目录 `.health-server.pid`，只管理自己启动的进程，不影响其他 Java 程序；
- 若服务已在运行则直接打开浏览器，不重复启动；
- 停止服务：双击 `停止服务.vbs`（按 PID 精准结束并释放 5500 端口）；
- 也可使用备用入口 `一键打开.bat`（效果一致）。

#### 方式三：线上部署（可选）

**第一步：部署静态站点。** 把整个项目目录（`index.html`、`workflow.html`、`chat.html`、`css/`、`js/`、`images/`）上传到任意静态托管（Vercel / Netlify / Cloudflare Pages / GitHub Pages / 对象静态托管均可），无需构建流程，入口为 `index.html`。

**第二步：部署 AI 代理（如需真实 AI）。** 在 Vercel / Netlify / Cloudflare Workers 任选其一创建 serverless 函数，把收到的 POST 请求体原样转发到 `https://api.deepseek.com/chat/completions` 并附加 `Authorization: Bearer <密钥>`（密钥放在平台环境变量中，如 `DS_API_KEY`），透传状态码与响应体。参考逻辑与项目内 `server.java` 的 `handleApiChat` 一致（CORS 放行 + 原样转发 + 透传）。

**第三步：配置并验证。** 把代理地址填入 `js/config.js` 的 `cloudProxyUrl`（如 `https://your-app.vercel.app/api/chat`），重新部署静态站点后打开网址即用。未配置时静态部署与 `file://` 模式一致，自动使用内置知识库，页面顶部会显示可关闭的模式提示。

> 线上部署后浏览器地址为 https 协议，`js/api.js` 的 `isFileMode()` 为假且非 localhost：会先尝试 `cloudProxyUrl`（若配置），再尝试 `http://localhost:5500/api/chat`，均不可达时走内置知识库。推荐正式部署时同时把 `apiKey` 置空，密钥只保留在云端代理环境变量中。

#### 排错入口：start.bat

`start.bat` 保留用于查看服务日志与排错：窗口标题友好、启动后自动打开浏览器、关闭窗口即停止服务。

## 故障排查

| 现象 | 原因与处理 |
| --- | --- |
| 双击 `一键打开.vbs` 提示「缺少 Java 环境」 | 未安装 JDK 17+。双击 `环境安装.vbs` 一键自动安装；或手动安装 Azul Zulu / Oracle JDK 并把 bin 目录加入 PATH；或改用方式一离线演示 |
| `环境安装.vbs` 自动安装失败 | 本机无 winget 或网络受限。按脚本弹窗指引到官方页面手动下载 MSI 安装 |
| 提示「端口 5500 被占用」 | 先双击 `停止服务.vbs`；仍占用则命令行执行 `netstat -ano \| findstr :5500`，在任务管理器结束对应 PID |
| 提示「启动超时 / 启动失败」 | 运行 `start.bat` 查看具体报错；查看项目目录 `server-run.log`；确认 JDK ≥ 17 |
| `停止服务.vbs` 提示「未找到服务进程记录」 | 服务未在运行或非脚本启动，可在任务管理器手动结束本项目 Java 进程 |
| 项目路径含中文 / 空格异常 | 脚本已按脚本所在目录定位（自动处理中文与空格），请勿把项目放入含特殊字符的路径 |
| 浏览器打开后 API 走了内置知识库 | 双击 `一键打开.vbs` 走真实 AI；或检查密钥、网络与 `js/config.js` 配置 |

## 三个页面的职责

| 页面 | 职责 |
| --- | --- |
| `index.html` | 首页：品牌与方案总览、三大核心能力、9 张技术图谱（点击灯箱放大）、亮点数据、三家临床合作案例 |
| `workflow.html` | 全流程页：以骶骨骨折为例的六步诊疗闭环——①患者多模态脱敏数据（可上传本机影像）→ ②AI 影像检测（视觉模型）→ ③3D打印内植物数据（23 行参数表 + Excel 下载）→ ④3D模型 → ⑤AI 诊疗方案 → ⑥AI 恢复计划（四阶段） |

## AI 代理与离线回退机制

- `server.java` 内置 `/api/chat` 反向代理：把前端请求原样转发到 DeepSeek 接口并透传状态码与响应体，处理 OPTIONS/CORS，连接超时 15 秒、读取超时 90 秒。
- `js/api.js` 的策略是「先代理、后直连」：
  - 页面运行在 `http://localhost:5500` 时走同源 `/api/chat`（不带 Authorization，密钥由服务端注入）；
  - 代理失败时自动降级为浏览器直连 DeepSeek（带 Bearer 密钥）；
  - 两者都失败时调用 `js/knowledge.js` 内置知识库回退，页面上以不打断演示的轻量提示告知。
- 页面打开时 `chat.html` 会做一次 API 自检（发送「请用两个字回复：正常」），成功时不显示任何提示，失败才显示黄色横幅「当前使用内置知识库回答，演示不受影响」。
- 因此**断网、密钥失效均可完整演示**，所有功能自动回退到内置数据。

## config.js 配置项

`js/config.js` 集中管理：

- `apiKey`：DeepSeek API 密钥（本地演示用；`server.java` 中的 `DS_API_KEY` 常量与之保持一致）
- `apiUrl`：`https://api.deepseek.com/chat/completions`
- `chatModel`：`deepseek-v4-flash`（对话 / 诊疗方案 / 恢复计划）
- `visionModel`：`deepseek-v4-flash-vision-exp`（CT 影像 AI 检测）
- `maxTokens`：2500（单次生成上限）
- `timeoutMs`：45000（请求超时）
- `cloudProxyUrl`：云端代理地址（默认空）。`file://` 直接打开模式下：非空则优先走该代理（不带 Authorization，适合部署 Vercel/Netlify/Cloudflare 的 serverless 代理）；为空则立即使用内置知识库，不做任何网络请求

更换密钥只需修改 `js/config.js`（直连场景）与 `server.java` 的 `DS_API_KEY`（代理场景）两处。

## Excel 下载

`workflow.html` 第 3 步的「⬇ 下载 Excel」由内置的 SheetJS（`js/vendor/xlsx.full.min.js`，完全离线）在浏览器本地生成 `智骨科技-3D打印内植物数据.xlsx`，含标题行、项目名称、生成日期、表头、23 行参数与备注，可直接用 Excel / WPS 打开，不依赖任何网络服务。

## file:// 直接打开的说明

若不启动本地服务、直接双击 HTML 文件（`file://` 协议）：

- 静态页面、图片、六步流程、内置知识库、Excel 下载全部可用；
- AI 实时生成部分不会尝试直连 DeepSeek（避免浏览器 CORS 报错与长时间等待）：若 `js/config.js` 的 `cloudProxyUrl` 非空则优先走该云端代理（不带 Authorization），否则**立即**回退到内置知识库；
- 页面顶部显示可关闭的模式提示，AI 回退提示与黄色横幅逻辑保持不变。

## 关于密钥安全的说明

仓库内的密钥**仅限本地演示使用**。正式上线时必须把密钥收敛到后端服务（由后端代理统一鉴权与转发），前端不得携带密钥，且请勿将密钥提交到任何公开仓库。
